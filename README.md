# 🏛️ Cavalcanti & Associados  
### Site Institucional de Advocacia (Projeto de Portfólio)

Bem-vindo(a)! 👋  
Este projeto foi desenvolvido como **demonstração profissional de portfólio**, com foco em um site institucional **moderno, elegante e confiável** para um escritório de advocacia fictício localizado em **Fortaleza – CE**.

A ideia aqui não é só “funcionar”, mas **transmitir credibilidade, sofisticação e autoridade**, que são valores essenciais para a área jurídica.

---

## 📌 Visão Geral do Projeto

**Nome do Escritório:** Cavalcanti & Associados  
**Slogan:** Advocacia de Excelência  

O site foi pensado para apresentar o escritório de forma clara e profissional, oferecendo uma ótima experiência tanto em desktop quanto em dispositivos móveis.

### Objetivos principais:
- Passar **confiança e seriedade**
- Ter um **design premium**, limpo e sofisticado
- Ser rápido, responsivo e bem estruturado
- Servir como um **case forte de portfólio**

---

## 🎨 Identidade Visual

### Paleta de Cores
- **Azul Marinho:** #1a365d → confiança, estabilidade e tradição  
- **Dourado / Bege:** #b8a26f → sofisticação e autoridade  
- Tons neutros para equilíbrio e leitura confortável

### Tipografia
- **Títulos:** Playfair Display (Serif) – clássico e elegante  
- **Textos:** Inter (Sans-serif) – moderno e legível  

---

## 🧠 Tecnologias Utilizadas

Este projeto utiliza um stack moderno e amplamente usado no mercado:

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animações suaves)
- **React Icons**
